Catatan Prototype

  • Frame gelap = modul TFT ~3.2" (280×380 portrait); area dalam = tampilan layar.
  • Interaksi di prototipe ini menggunakan klik mouse — di perangkat asli menggunakan 2 tombol fisik (A/B) berukuran besar.
  • LED indikator kapasitas (Sharp = Benda Tajam, Infeksius): hijau → kuning → merah berkedip.
  • Fail-safe: jika tidak ada input selama 60 detik, limbah otomatis diarahkan ke safety box (benda tajam).
  • Level 1 (Tenaga Medis) = buang limbah. Level 2 (Petugas Kebersihan) = ambil kompartemen.
